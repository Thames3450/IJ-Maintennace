# ข้อกำหนดระบบ Login และสิทธิ์ — รอพัฒนา

เอกสารนี้เป็นข้อกำหนดที่ตกลงกัน ยังไม่ได้เปิดระบบ Login ในรุ่น 13.11.3

- ลงทะเบียนแล้วรอ Engineer/Admin ตรวจสอบและอนุมัติสิทธิ์ ผู้สมัครกำหนดสิทธิ์จริงเองไม่ได้
- Engineer/Admin ทำได้ทุกหน้าที่ รวมตรวจเครื่อง รับมอบหมายงาน ซ่อม บันทึกผล วางแผน ตรวจรับ อนุมัติ และจัดการระบบ
- อภิวุฒิ และ รัฐธรรมนูญ เป็น Engineer เชื่อมกับรายชื่อพนักงานเดิม และแสดงให้เลือกในผู้รับผิดชอบงานด้วย
- ช่างตรวจเครื่อง รับงาน บันทึกงานและรูป ส่งตรวจรับ
- ผู้จัดการดูภาพรวม สุขภาพเครื่อง Loss Time รายงาน และปฏิทิน PM/TPM ได้ทั้งหมด พร้อมอนุมัติหรือส่งกลับพร้อมความเห็น
- Planning หมายถึง Production ดูปฏิทิน ยืนยันช่วงหยุดเครื่อง เสนอเลื่อนพร้อมเหตุผล และรับเครื่องกลับผลิต
- เชื่อมผลตรวจ งานติดตาม และ TPM ให้บันทึกผลครั้งเดียว ตรวจรับแล้วอัปเดตต้นทาง ไม่ปิดงานที่ยังแก้ไม่ครบ
- ซ่อมเสร็จกับกลับมาผลิตเป็นคนละสถานะ แยก Breakdown Loss Time ออกจากเวลาหยุดตามแผน
- บังคับสิทธิ์ที่ฐานข้อมูลและไฟล์แนบด้วย ไม่ใช้แค่ซ่อนปุ่มหน้าเว็บ

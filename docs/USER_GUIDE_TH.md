# วิธีใช้ IJ Maintenance v13.11

## เลือกจากงานที่กำลังจะทำ

| งานหน้างาน | กดเมนู |
|---|---|
| เดินตรวจเครื่องตามรายการ | ตรวจสภาพเครื่อง |
| พบปัญหาเฉพาะจุด เช่น สายลมรั่ว | พบปัญหา / แจ้งจุดผิดปกติ |
| ลงมือแก้ไขปัญหาที่เคยแจ้งแล้ว | แก้ไขและติดตามปัญหา |
| ทำ PM ตามรอบ | มาตรฐานและทำ PM |
| ทำงาน TPM / งานตามสภาพ | วางแผนและทำ TPM |

## ตรวจสภาพ

1. กดเริ่มตรวจแล้วเลือกเครื่อง
2. เลือกรายการตรวจที่ต้องการ หากไม่มีรายการจากฐานข้อมูล ใช้รายการตรวจพื้นฐาน IJ ได้
3. อ่านวิธีตรวจของแต่ละข้อ แล้วเลือก **ปกติ / เฝ้าระวัง / ผิดปกติ / ไม่เกี่ยวข้อง**
4. ข้อที่เฝ้าระวังหรือผิดปกติต้องระบุสิ่งที่พบ แนบรูปได้ หากรายการกำหนดว่าต้องมีรูป ระบบจะตรวจให้
5. กรอกค่าที่วัดเมื่อมีช่องค่าและหน่วย
6. กดบันทึกเมื่อเลือกผลครบ หากพบความผิดปกติจะมีงานติดตามให้
7. ย้อนดูได้ด้วยปุ่ม **ดูผลตรวจ**

รายการพื้นฐานเป็นการตรวจสภาพจากภายนอก งานซ่อม การเข้าเขต Robot เปิดตู้ไฟ หรือทดสอบระบบนิรภัย ให้ทำในช่วงหยุดเครื่องตามขั้นตอนของโรงงาน

## พบปัญหา

เลือกเครื่อง → ระบุปัญหา → เลือกระดับ A/B/C → ระบุผลกระทบและแนบรูป → บันทึก

จากนั้นเปิดงานติดตามของปัญหานั้น ไม่จำเป็นต้องแจ้งปัญหาเดิมซ้ำ

## แก้ไขและติดตาม

เมื่อผลตรวจผิดปกติ รายการจะอยู่ในทะเบียนจุดผิดปกติและงานติดตาม เป็นปัญหาเดียวกัน ไม่ต้องแจ้งซ้ำ

**แก้ไขโดยตรง:** กด **อัปเดตงาน** เลือกสถานะและผู้รับผิดชอบ ใส่งานที่จะทำ/กำหนดเสร็จตามงานจริง แล้วบันทึก เมื่อทำเสร็จ กด **บันทึกผลและปิดงาน** ระบุคนรับผิดชอบ ผลที่ทำจริง และผลตรวจยืนยัน แล้วกด **ยืนยันและปิดงาน** รายละเอียดอะไหล่และการควบคุมชั่วคราวเปิดเพิ่มได้เมื่อจำเป็น

**ทำผ่าน TPM:** เปิด **เพิ่มเติม > นำเข้าแผน TPM** จากปัญหานั้น เมื่อมีแผนแล้ว กด **ทำงานผ่าน TPM** เพื่อเปิดงานเดิม ไม่สร้างแผนซ้ำ ตอนปิด TPM กรอกผลทำงานกับผลตรวจยืนยันเพียงครั้งเดียว ระบบปิดงานติดตามต้นทางให้พร้อมกัน

ถ้าทำบางส่วน ยังต้องติดตาม หรือมี TPM อื่นที่เชื่อมไว้ยังไม่เสร็จ งานติดตามจะยังเปิดอยู่ ถ้าแก้ไขครบแล้วแต่จะตรวจยืนยันภายหลัง ให้เอาติ๊ก **ปิดงานติดตามพร้อม TPM** ออก ผลแก้ไขจะส่งกลับและขึ้น **รอตรวจยืนยัน**

ผล TPM รุ่นเก่าที่ปิดแล้วจะเติมมาให้ในฟอร์มปิดงานติดตาม ตรวจข้อมูลและกรอกผลยืนยันได้เลย ไม่ต้องพิมพ์ผลงานเดิมซ้ำ

## TPM

1. เลือกวันที่ในปฏิทินแล้วสร้างแผน
2. ระบุเครื่อง งานที่จะทำ และผู้รับผิดชอบ
3. ยืนยันฝ่ายผลิตและอนุมัติแผนตามขั้นตอน
4. กดเริ่มงานเมื่อพร้อม
5. กดปิดงาน ระบุสิ่งที่ทำจริง เวลาหยุดจริง และอะไหล่ที่ใช้ ถ้างานเชื่อมมาจากงานติดตาม ให้กรอกผลตรวจยืนยันเพื่อปิดทั้งสองรายการพร้อมกัน
6. หากทำไม่ครบ เลือก **เสร็จบางส่วน** พร้อมระบุงานที่ยังเหลือ แล้วกด **ทำต่อ** ในรอบถัดไป

งานเสร็จบางส่วนยังไม่ถูกนับว่าเสร็จครบในความคืบหน้า

## PM ตามมาตรฐาน

เปิด **มาตรฐานและงาน PM** → ใช้แม่แบบและทวนสอบเกณฑ์ → รับรองมาตรฐาน → จัดรอบ PM → เริ่มทำ PM → บันทึกผลรายข้อ → ปิด PM และคืนเครื่อง

ถ้าทำไม่ครบ กด **บันทึกไว้ทำต่อ** งาน PM มีประวัติของตัวเองและปรากฏในประวัติเครื่อง อ่านรายละเอียดใน `PM_STANDARD_TH.md`

## ถ้าบันทึกไม่สำเร็จ

อ่านข้อความในกรอบแดง ข้อมูลที่กรอกยังอยู่ในฟอร์ม หากแจ้งว่าบันทึกได้บางส่วนและล้างข้อมูลไม่สำเร็จ ให้รีเฟรชตรวจประวัติก่อนกดซ้ำ หากแจ้งว่ารูปอัปโหลดไม่ครบ ให้ตรวจรูปของรายการที่บันทึกแล้ว

Dropdown มีช่องค้นหาและปุ่มปิด เลือกแล้วจะปิดอัตโนมัติ บนคอมใช้ Escape เพื่อปิด หรือใช้ลูกศรและ Enter เพื่อเลือกได้


### รูปภาพและป้าย QR (v13.7)
- เลือก “ถ่ายรูป” เพื่อเปิดกล้อง หรือ “เลือกจากเครื่อง” เพื่อเลือกรูปที่ถ่ายไว้จากแกลเลอรี/ไฟล์ บนคอมพิวเตอร์ปุ่มถ่ายรูปอาจเปิดหน้าต่างเลือกไฟล์ตามเบราว์เซอร์
- ที่ศูนย์ข้อมูลเครื่องจักร ค้นหา/กรองเครื่อง แล้วพิมพ์ QR ทั้งกลุ่มหรือทีละเครื่องได้ ที่ประวัติเครื่องมีปุ่มพิมพ์ QR เช่นกัน
- ตรวจ URL เว็บจริงรวม path โครงการก่อนพิมพ์ เลือกเครื่อง แล้วกดพิมพ์/บันทึก PDF ป้ายจัดสองคอลัมน์บนกระดาษ A4 ตั้งสเกล 100% และปิดหัวท้ายกระดาษของเบราว์เซอร์
- สแกน QR จะเปิดประวัติรวมของเครื่องนั้น (ซ่อม PM TPM ตรวจสภาพ จุดผิดปกติ) ในเว็บเดิม เครื่องที่ไม่มีประวัติจะแสดงข้อมูลเครื่องพร้อมหน้าว่าง
- ต้องนำ v13.7 ขึ้นโฮสต์ก่อนติดป้าย และสแกนทดสอบจากมือถือบนเครือข่ายที่จะใช้งาน



## ลบรายการอย่างมั่นใจ

1. กด **ลบรายการ** จากรายการที่ต้องการ (ในงานติดตามอยู่ใต้ **เพิ่มเติม**) สำหรับ TPM เลือก **ลบงาน** หรือ **ลบทั้งแผน**
2. ตรวจชื่อเครื่อง ชื่องาน และจำนวนรายการในหน้าต่างยืนยัน
3. ติ๊ก **ฉันตรวจสอบรายการที่จะลบแล้ว** แล้วกด **ยืนยันลบ** ถ้าเปลี่ยนใจ กด **ยกเลิก**

รายการจะหายจากหน้าระบบ IJ โดยข้อมูลเดิมและรูปยังเก็บอยู่ งานที่เชื่อมกันไม่ถูกลบตาม เช่น ลบผลตรวจแล้วงานติดตามยังอยู่ หน้ายืนยันบอกผลที่จะเกิดก่อนกดลบเสมอ
